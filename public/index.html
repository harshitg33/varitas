Agents How it works

Research,
beyond answers.

Ask a question. A team of agents plans the work, reads the web, checks the facts, and writes a report where every claim points to its source.

Five specialists.
One careful report.

Orchestrator

Breaks your question into focused subtasks and shows you the plan first. Edit it, remove steps, or add your own before anything runs.

Research

Searches the web in parallel and extracts what each source actually says.

Analysis

Finds patterns across sources and points out where they disagree.

Fact-checking

Tests the key claims against the retrieved evidence and marks each one supported, partial, or not.

Writer

Turns verified findings into a structured report with numbered citations. You review it, approve it, and export it as PDF or Markdown.

You stay in control.

  1. Review the plan.Nothing is searched until you approve the subtasks.
  2. Watch it work.Follow each agent as it moves through your question.
  3. Read with receipts.Every claim carries a number that links to its source.
  4. Approve and export.Download a clean PDF or Markdown file when you are happy.
Veritas checks claims against the sources it retrieves. It can still be wrong, so open the sources for anything important.
